So geht'sHow it works

  1. Display per USB-Kabel an den PC anschließen (Datenkabel, kein reines Ladekabel).
  2. Oben die Sprache wählen, auf Installieren klicken und im Fenster den Anschluss wählen (meist „USB-SERIAL CH340“ oder „CP210x“).
  3. Warten, bis „Installation complete“ erscheint, dann das Display neu starten.
  4. Am Handy mit dem WLAN SOC-Victron-… verbinden (Passwort panelsat) – die Einrichtung öffnet sich von selbst.
  1. Connect the display to the computer with a USB cable (a data cable, not a charge-only cable).
  2. Choose the language above, click Install and pick the serial port in the dialog (usually “USB-SERIAL CH340” or “CP210x”).
  3. Wait until “Installation complete” appears, then restart the display.
  4. On your phone, join the WiFi SOC-Victron-… (password panelsat) – the setup page opens by itself.
Achtung: Das Aufspielen hier löscht alle Einstellungen (WLAN, Geräte, Kacheln). Ein schon eingerichtetes Display bitte über seine eigene Weboberfläche aktualisieren (Firmware → Update-Modus, Datei ota/victron-display-cyd.bin).Note: Installing here erases all settings (WiFi, devices, tiles). To update a display that is already set up, use its own web interface (Firmware → Start update mode, file ota/victron-display-cyd-en.bin).

  • Try another USB cable – many cables only charge.
  • Install the driver for the USB converter (CH340 or CP210x).
  • If writing aborts: connect the display through a powered USB hub.
