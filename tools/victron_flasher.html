Victron-Display aufspielen

Firmware für das ESP32-2432S028R („Cheap Yellow Display“) direkt aus dem Browser – ohne Programme.

So geht's

  1. Display per USB-Kabel an den PC anschließen (Datenkabel, kein reines Ladekabel).
  2. Auf Installieren klicken und im Fenster den Anschluss wählen (meist „USB-SERIAL CH340“ oder „CP210x“).
  3. Warten, bis „Installation complete“ erscheint, dann das Display neu starten.
  4. Am Handy mit dem WLAN SOC-Victron-… verbinden (Passwort panelsat) – die Einrichtung öffnet sich von selbst.
Achtung: Das Aufspielen hier löscht alle Einstellungen (WLAN, Geräte, Kacheln). Ein schon eingerichtetes Display bitte über seine eigene Weboberfläche aktualisieren (Firmware → Hochladen, Datei ota/victron-display-cyd.bin).

Dein Browser kann nicht auf USB zugreifen. Bitte Chrome oder Edge am PC/Mac verwenden.

Diese Seite muss über https geöffnet werden.

Kein Anschluss in der Liste?

  • Anderes USB-Kabel probieren – viele Kabel laden nur.
  • Treiber für den USB-Wandler installieren (CH340 bzw. CP210x).
  • Bricht das Schreiben ab: Display über einen USB-Hub mit eigenem Netzteil anschließen.

English

Connect the display via USB, click Installieren (install) and pick the serial port (Chrome or Edge on a desktop). This erases all settings – to update a display that is already set up, use its own web interface (Firmware → Hochladen). Afterwards join the WiFi SOC-Victron-… (password panelsat).
